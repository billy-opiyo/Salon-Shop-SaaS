# Beauty Sphia Platform Assets

Place images used by the Beauty Sphia platform homepage in this folder.

Suggested filenames:

- `beauty-sphia-splash.jpg` for the platform splash screen
- `platform-hero.webp` for the platform homepage hero
- `store-preview.webp` for the Browse Stores preview

These assets are served from `/platform/<filename>`.

Keep Royal Braids storefront assets in `../reference/IMG`.
